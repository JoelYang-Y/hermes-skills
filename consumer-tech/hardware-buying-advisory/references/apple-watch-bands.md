# Apple Watch 表带：兼容矩阵与 Ultra 专属款

## 一、表壳尺寸兼容矩阵（官方口径，support.apple.com/zh-cn/108908）

| 表带规格 | 可装表壳 |
|---|---|
| 38 / 40 / 41mm（含 S10/S11 的 42mm 小尺寸） | 38、40、41、42mm(S10/S11) |
| 42mm(S3) / 44 / 45 / 46mm | 44、45、46、49mm |
| **49mm（Ultra 专属）** | **44、45、46mm**（官方称兼容） |

实际贴合注意：

- 49mm 表带装 **49mm（Ultra）机身**：原生尺寸，等宽同弧，无台阶无缝隙。
- 49mm 表带装 **46mm 机身**：官方说兼容，但 Ultra 表带连接部按「精准贴合」设计、公差更紧，社区多例反馈偏紧甚至插不到底；建议到直营店实装再买。装上后表带比表壳略宽约 1–2mm，属正常，不是假货。
- 小尺寸组表带塞大机身：能插但留缝，官方不背书。

## 二、49mm 钛金属米兰尼斯表带（Titanium Milanese Loop）

官网现价 **¥1,779**（24 期 ¥75/月），仅 49mm 一种规格，原色钛 / 黑色钛两色。每次核价都重新抓 apple.com.cn 商品页，勿引用旧报价。

| 项 | 规格 |
|---|---|
| 材质 | 航空级钛金属织网，95% 再生钛 |
| 扣合 | 降落伞式**机械卡扣，非磁吸**；夹扣抬起可微调松紧 |
| 重量 | 约 30g（社区实测） |
| 尺码 | S 130–160mm / M 155–185mm / L 180–210mm 腕围 |
| 防水 | 可海水/泳池/桑拿，脏了直接水冲 |

优点：轻、哑光不发假亮、运动中不滑松（机械扣的关键优势）、织网密网孔大所以夹毛明显少于不锈钢米兰尼斯、钛硬度高于不锈钢不易留深痕。

代价：价格高（≈ Ultra 机身价 27%）；偏硬挺，睡觉戴压迫感明显；卡扣需双手捏开，单手摘戴不如磁吸；表扣长期开合在表带背面磨出亮痕；钛硬度高于铝合金，会刮花 MacBook 掌托；黑色款涂层磨亮后露底更显旧，介意选原色。

搭配：原色表带配原色机身、黑色表带配黑色机身；表壳喷砂与表带织网的表面处理不同，轻微质感差属正常。

## 三、Ultra 4 的随机表带

Ultra 4（49mm，黑 / 原色钛两色）随机表带四选一：高山回环、野径回环、海洋、钛金属米兰尼斯。前三款全是运动取向，**钛金属米兰尼斯是这四款里唯一能进正式场合的**——所以对 Ultra 用户它是「补缺口」，对非 Ultra 用户才是「为质感买单」。

## 四、副厂平替

钛金属米兰尼斯副厂 ¥200–500，织网密度、卡扣公差、钛纯度差距肉眼可见，用在高价机身上不建议。仅当用户明确只要「远看像」再考虑。
