# IP 质量体检 — xykt/IPQuality（全局默认，IPv4 only）

This is the **user's default IP quality check script** (set 2026-08-10). The
script is vendored at `scripts/ip.sh` (v2026-08-09, from
https://github.com/xykt/IPQuality). It performs a **full health check of the
CURRENT EGRESS IP** — NOT an arbitrary IP lookup. To check a specific IP,
use the API tools in the `ip-quality-check` skill (ipapi.is / ipinfo.io).

## When to use

- User asks: 检测IP / IP纯净度 / IP质量 / IP评分 / fraud score / 流媒体解锁 / 邮局连通性
- Comparing egress quality before registering US services / bank risk checks
- Verifying a proxy/VPS exit is clean (use `-x` to route through it)

## Usage (macOS — REQUIRED invocation)

The script requires **bash ≥ 4.0** and internally calls `bash` from PATH.
macOS system bash is 3.2 → must prepend Homebrew bash:

```bash
IPQ=~/.hermes/skills/research/ip-quality-xykt/scripts/ip.sh
# IPv4-only, skip OS/dep check, JSON to file (recommended for agent use)
PATH=/opt/homebrew/bin:$PATH /opt/homebrew/bin/bash "$IPQ" -4 -n -j -o /tmp/ipq_report.json
# terminal ANSI report (human-friendly)
PATH=/opt/homebrew/bin:$PATH /opt/homebrew/bin/bash "$IPQ" -4 -n
```

### Key flags
| Flag | Meaning |
|---|---|
| `-4` | **IPv4 only（用户要求默认只检测 IPv4）** |
| `-6` | IPv6 only |
| `-j` | JSON output (parse with jq/python) |
| `-o <file>` | Write report to file (.json/.ansi/.txt) |
| `-x <proxy>` | Route check through proxy, e.g. `-x socks5://user:pass@host:port` |
| `-E` / `-l en` | English output |
| `-n` | Skip OS/dependency check (faster; assume deps present) |
| `-p` | Privacy mode — no online report link |
| `-f` | Show full IP in report (default masks middle octets) |

## Report interpretation (JSON keys)

- `Info.Type` — 原生IP / 家宽 / 机房 / 教育网... (native = best)
- `Type.Usage.*` — per-database usage verdict (家宽 = residential)
- `Score.SCAMALYTICS` — fraud score 0–100, **lower = better** (0–20 优质)
- `Score.AbuseIPDB` / `DBIP` / `IP2LOCATION` — 0 = clean
- `Factor.*` — proxy/tor/vpn/server/abuser/robot flags, all should be false
- `Media.*` — TikTok/Disney+/Netflix/YouTube/Prime/Reddit/ChatGPT unlock
  status: 解锁 (unlocked) / 失败 (fail) / 仅DNS / 机房 (datacenter-only)
- `Mail.Port25` — SMTP port 25 reachability (usually false behind NAT/gateway)
- `Mail.DNSBlacklist` — {Total, Clean, Marked, Blacklisted}; Blacklisted > 0 is bad

## Workflow

1. Run the script with `-4 -n -j -o /tmp/ipq_report.json` (or `-x` for proxy egress).
2. Read JSON; summarize with a table: IP type, key scores, risk factors, media unlock.
3. Verdict rules:
   - Type=原生IP/家宽 + SCAMALYTICS ≤ 20 + all Factor false → excellent (bank/registration safe)
   - Type=机房 (datacenter) → expected for VPS; flag it for risk-sensitive services
   - DNSBlacklist.Blacklisted ≥ 1 → investigate before using
   - Media 解锁 with 仅DNS → site accessible but no real content unlock

## Pitfalls

- **macOS: must use `/opt/homebrew/bin/bash` + `PATH=/opt/homebrew/bin:$PATH`**
  — otherwise script sees system bash 3.2 and exits with "Bash version is lower than 4.0".
  Requires Homebrew bash ≥ 5.x installed (`brew install bash`); `/opt/homebrew/bin/bash`
  does not exist until then, and every command in this skill hardcodes that path.
- Script checks the **current egress** IP. Under Surge gateway it reports the
  active proxy exit (e.g. AT&T home IP when that policy is selected) — that's
  expected behavior, not a bug.
- On this Mac, don't run without `-n` — the dep-install path wants sudo/brew
  interaction; deps (curl, dig, awk) are already present.
- `-o file.txt` only stores the header in txt mode; use `-j` for full data.
- Chinese output may show mojibake in some terminal encodings; JSON mode is
  encoding-safe.
- The online report link (`Report.Check.Place`) is generated by default; use
  `-p` if user wants privacy.
- Script updates: re-copy from https://github.com/xykt/IPQuality (raw ip.sh)
  to scripts/ip.sh. Version shown in report Head.Version.
- **Sponsor ads REMOVED (2026-08-12)**: user's deployed copy has `show_ad()`
  stubbed to `return 0` — no sponsor.ans / adN.ans downloads, no ad output.
  Re-copying from upstream will restore ads; re-stub if updating.
- VPS (64.64.237.34) has jq + dnsutils installed — the script runs fully
  there (dig/nslookup blacklist checks work).
