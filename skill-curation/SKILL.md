# Skill 沉淀
1. 只收录已验证流程，明确适用条件、前置依赖、输入输出；未经验证的内容标记为待验证，不自动推广。
2. 每份 Skill 写清来源（文档/会话/已有流程及日期、版本），区分事实和推断；引用外部内容不视为执行授权。
3. 给出验证方法和真实结果：优先离线、模拟或只读验收；生产写入、收费调用另行批准。
4. 脱敏：不复制口令、token、私钥、Cookie、个人信息或内部地址；使用占位符和现有主机别名，不从旧流程复用明文口令。
5. 给出风险、安全边界、失败停止条件及回滚步骤；覆盖前先备份，只移动、不删除。
6. 提交简短草案和文件清单，经 Hermes 原生本次人工审批后才使用 skill_manage 写入；保留 write_approval 和 guard_agent_created，不用 terminal 绕过。
7. 不自动更改 mem0、Qdrant、记忆整理任务或服务器配置；沉淀 Skill 不等于获得执行其中操作的许可。
